# TuneHive

A clean, minimal offline music player for Android and iOS. It plays the audio
files already on your phone — no account, no internet, no streaming.

## Features

- Onboarding with slide-to-start
- Home: categories, popular songs, recently played (last 4), all songs
- Search across your own library, favourites, playlists, history with play counts
- Full player: rotating disc (turn it with a finger to change volume), seek bar,
  play/pause, previous/next, +/-10s, shuffle, repeat off/all/one,
  speed 0.5x-2x, sleep timer with custom minutes, queue with drag-to-reorder
- Background playback with lock-screen controls (previous / play / next) and a
  softly blurred version of the artwork in the notification
- 5-band equalizer with Flat / Bass / Vocal / Treble presets (Android)
- The queue survives app restarts

## Permissions

Only what is needed:

- audio files (`READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE` up to Android 12)
- notifications (`POST_NOTIFICATIONS`) for the playback controls
- foreground service, so music keeps playing in the background

No internet, camera, contacts or location permission is requested.

## Run locally

```
flutter pub get
flutter run
```

The `android/` folder is generated by the GitHub Actions workflow. To build
locally, run `flutter create . --platforms=android` once (iOS needs macOS +
Xcode, plus `UIBackgroundModes: audio` in Info.plist for background playback).

## APK

Push to `main`, or run the **Build APK** workflow manually. The APK appears in
the workflow artifacts and in a GitHub Release.
