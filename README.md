# TuneHive

A clean, minimal music player for Android and iOS. Plays the audio files
already on your device plus free Creative Commons music streamed from the
Internet Archive.

## Features

- Onboarding, home (categories, popular songs, new collections), search,
  favourites, playlists, profile/settings
- Full player: rotating disc, seek bar, play/pause, next/previous, ±10s,
  shuffle, repeat off/all/one, playback speed 0.5x–2x, sleep timer
  (including "end of track"), queue with drag-to-reorder
- Background playback with lock-screen controls
- Device library: every audio file longer than 30 seconds, embedded artwork
  when present, gradient placeholder when not
- Online: Creative Commons audio from the Internet Archive — no API key,
  no login. Offline? The app simply falls back to device songs.
- Permissions asked for: audio files, notifications (for the playback
  controls) and internet. Nothing else.

## Online music setup

Jamendo (full legal tracks) needs a free Client ID. See
[JAMENDO_SETUP.md](JAMENDO_SETUP.md) — one GitHub secret and every build has
it built in. Without it the app automatically uses Audius and the Internet
Archive, so the online section still works.

## Run locally

```
flutter pub get
flutter run
```

The `android/` folder is generated by the GitHub Actions workflow. To build
locally, run `flutter create . --platforms=android` once (iOS needs macOS +
Xcode, plus `UIBackgroundModes: audio` in Info.plist for background playback).
For iOS app icons, set `ios: true` under `flutter_launcher_icons` in
pubspec.yaml and run `dart run flutter_launcher_icons` after that.

## APK

Push to `main`, or run the **Build APK** workflow manually. The APK appears in
the workflow artifacts and in a GitHub Release.
